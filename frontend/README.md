# TaskFlow Frontend

This is the Single Page Application (SPA) frontend for **TaskFlow — Mini Task Management System**.

## Tech Stack
- **React.js 18**
- **React Router v6**
- **Vite**
- **Lucide React**
- **Custom Modern SaaS CSS**

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

### 3. Production Build
```bash
npm run build
```
Generates production-ready optimized assets in `dist/`.
